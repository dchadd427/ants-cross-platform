# Security policy

Thank you for looking after Ants! and the people who play it.

## Reporting a vulnerability

Please report a vulnerability privately, so that it can be fixed before it is public:

1. Open the **Security** tab of this repository and choose **Report a vulnerability** (GitHub's private vulnerability reporting).
2. Say what you found, where it is (a file, a page or an address), the steps that show it, and the version or build id (the footer of the web page shows both).

Please do not open a public issue or pull request, or post in a chat, about a problem that is not fixed yet, and please leave other people's personal data out of a report.

## What is in scope

- The code in this repository: the game, the match server, the chat hub, the web pages, the Docker files and the CI configuration.
- The public site, beta.playants.org, as it runs this code.

Only the latest version is supported: the one on `main` and on the beta site.

Please try things on your own copy of the code where you can. On the public site keep to ordinary requests: no load or flood tests, no reading of other players' data, nothing that disturbs the people who play. Problems in services we do not run (GitHub, Discord, your own browser or network) are for their operators.

## What to expect

We will acknowledge your report within a few days, tell you whether we can reproduce it, and keep you posted until it is fixed. If you would like credit once the fix is out, say so in your report. There is no bounty. Please give us a reasonable time to fix a problem before you share it.

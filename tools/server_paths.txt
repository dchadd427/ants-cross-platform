# The paths of the game server, the site's services and their tests. One list: tools/server_paths.py reads it (tests/scripts/test_server_paths.py checks it), and a tool or a test
# that needs it goes through that module.
#
# One pattern per line:
#   dir/     everything under the directory
#   a*b      a glob: * matches inside one path component and never across a /
#   a/b.c    anything else is the exact path of one file
# '#' starts a comment (a whole line, or the end of one); blank lines are ignored; there is no negation.
# `python3 tools/server_paths.py --check` fails for a pattern that matches no tracked file. A file that belongs with the server, the hub or the site gets its line in the change that
# adds it (a directory or a glob line covers the new files that fit it).
# What is not listed is the game: its libraries, the native and the web clients, the front page and Home, the map maker with its submit client, the replay page, and the tests that
# run without the server.

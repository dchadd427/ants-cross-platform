# The names of the computer players (docs/BOTS.md, "Names"). The ONE source of the list: tools/gen_bot_names.py writes the C++ table (src/ants_ai/bot_names_data.inc) and the
# JavaScript table (the generated block of web/front/bot_names.js) from it, and a test fails when either file differs from what the generator makes.
#
# One name per line; blank lines and lines that start with # are ignored. A name is a capital letter and 2 to 8 small letters (3 to 9 letters, ASCII), so that
# the HUD label "Name (bot)" is 15 characters at most. No two names are the same in any case, none is a word of tests/data/bot_names_blocklist.txt, and none is one of the
# twelve names that the web page offers a visitor (web/front/lobby_rules.js NAMES), so that a bot is not mistaken for a person who took the page's suggestion.
#
# THE ORDER IS PART OF THE PICKER: pick_bot_names(key, count) draws indexes into this list, so moving, removing or inserting a name changes which name a key gives (the golden
# vectors in tests/data/bot_names_golden.txt change with it). New names go at the END. A match stores the strings it was given, never the indexes, so old matches are not affected.
#

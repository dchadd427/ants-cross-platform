# allowlist.txt: the paths that the export copies to the public repository (with their history). Everything NOT matched here is private (private.txt).
# export/classify.py checks that every tracked file is matched by exactly one of the two lists (export/README.md: which list a new file goes on, and how to run the check).
# Syntax (one pattern per line, '#' starts a comment, blank lines are ignored):
#   dir/**         everything under dir (any depth)          dir/prefix*    files directly in dir (no slash) whose name starts with prefix
#   path/to/file   exactly that file                          !pattern       removes earlier matches of THIS list (last matching line wins)
# A path is "in" a list when its last matching pattern is not negated. A new file that matches neither list (or both) fails the check: nobody guesses.
# 'overlay' paths: export/overlay/<path> is exported to <path> (files that must read differently in the public repository: AGENTS.md, README.md, SECURITY.md, the CI workflow).
# A pattern that matches no file yet is a planned file of a later change (`classify.py --dead` lists them); it is kept so that the file is classified the day it arrives.

# What the test suites cover

Part of [Testing and CI](TESTING.md), where the tiers, the rules for tests and CI are. The python tests of suite 5.2 are in [The python tests](TESTING_PYTHON.md).

## What the Suites Cover

The numbers are `./run_tests.sh`'s; `--list` names every suite with its tier. A "full tier" suite is not in `--fast`. Section numbers (as in "section 5.32") are those of [`GAME_REVERSE_ENGINEERING.md`](GAME_REVERSE_ENGINEERING.md), where the rule that a suite checks is written down.

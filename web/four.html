Host a match on the game server and share its code or links, or join a match with its code. You can also play every seat yourself, on this page or in windows of their own.

New match

The page makes a code for the match; the room is made on the server when the first player connects, and waits up to ten minutes for the others. The match starts by itself when all its seats are taken (there are no computer players in these rooms yet), and a running match takes nobody new. Afterwards you choose, seat by seat, whether you play it on this page, in a window of its own, or send its link to somebody else.

Join a match

The code of a match that somebody else made here (they see it above their seats). It takes you into the game in this window and gives you the first free seat; the match starts by itself when all its seats are filled.

Waiting for the games to connect and start...
Every window runs the whole simulation; the server only orders the commands and acts as the referee. Each game tells this page its tick and state hash every 100 ticks (5 seconds): when the seats that report agree, the machines are in step (a seat that plays on another computer cannot report to this page). Click a window of this page to play it (the others stop their music and their sound: only the window you are in is heard). The match is the original's clock: when it ends each window shows its results screen.
